# Project Phoenix

A structured learning repository for Linux system commands, Bash scripting, C programming, and practical exercises.

---

## 📁 Repository Structure

```text
pro-phoenix/
├── README.md                  # Project overview and index
├── commands.md                # Quick-reference cheat sheet for Linux & Bash
│
├── bash/                      # Shell scripting practice and lessons
│   ├── concepts/              # Core language features (variables, loops, arrays, etc.)
│   ├── exercises/             # Practical coding problems (prime check, factorial, etc.)
│   └── notes/                 # Lecture logs and study notes
│
├── you_suck_at_programming/   # Exercises and tasks from the "You Suck at Programming" series
│   ├── greet
│   ├── greeter
│   ├── loop
│   └── task1 - task3
│
├── src/                       # Application and language source code
│   ├── c/                     # C programming experiments (e.g., first.c)
│   └── python/                # Python scripts and applications
│
├── docs/                      # Documentation and specifications
│   └── shared_docs/           # Team guidelines and API documentation
│
├── config/                    # Configuration files
│   └── config.json
│
└── scratch/                   # Temporary scratchpad notes and test files
```
